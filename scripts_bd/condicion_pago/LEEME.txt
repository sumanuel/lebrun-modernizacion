SCRIPTS DE CONDICION DE PAGO Y FORMA DE PAGO
============================================

Cambian la tabla sisadm.admcondpago para que sea la unica fuente de condiciones de pago (Contado, 30 dias, ...) y, mas adelante, de
formas de pago (Efectivo, Tarjeta, Divisa, ...), y pasan lo que estaba guardado como texto a codigos.
Los scripts son para MySQL 5.5 y MariaDB. Se pueden ejecutar mas de una vez sin dañar nada.

Orden de ejecucion (cada uno tiene su archivo _revertir; para revertir se va en el orden inverso: 4, 3, 2, 1)
  01_condicion_pago_estructura.sql      agrega conp_tipo (C condicion / F forma de pago) y conp_siglas (hasta 4 letras) y pone siglas
                                        sugeridas a las condiciones que ya existen.
  02_condicion_pago_migracion.sql       clientes y documentos que tenian el texto "Contado" pasan al codigo 07, la mora de "Contado" pasa
                                        al 07 y se elimina la fila duplicada de codigo "Contado". Guarda copia de todo lo que cambia
                                        (tablas bk_condpago_cambios y bk_condpago_condiciones).
  03_condicion_pago_menu.sql            (base sysconf) deja la pantalla de mantenimiento en Tesoreria > Fichero > Marcas Financieras.
  04_formas_pago.sql                    agrega conp_req_banco y conp_grupo y crea las formas de pago F01 a F07 (Efectivo, Tarjeta de Debito,
                                        Tarjeta de Credito, Cheque, Divisa $, Divisa Euro, Cachea). Desde aqui mocv_forpag guarda el codigo.

Como se ejecutan (con cualquier cliente de MySQL; cada archivo ya indica la base con USE):
    mysql -u usuario -p < 01_condicion_pago_estructura.sql
    mysql -u usuario -p < 02_condicion_pago_migracion.sql
    mysql -u usuario -p < 03_condicion_pago_menu.sql
    mysql -u usuario -p < 04_formas_pago.sql

Importante
- Hacer respaldo de la base antes de ejecutar el paso 2.
- Ejecutar los scripts ANTES de instalar la version del programa que usa codigos: la version nueva busca la condicion por codigo.
- La aplicacion lee el menu al iniciar sesion: despues del paso 3 hay que cerrar sesion y volver a entrar.
- Las tablas bk_condpago_* quedan como respaldo; se pueden borrar a mano cuando ya no hagan falta.
- Probados en la copia local (MariaDB 10.4): aplicar, revertir y aplicar otra vez.
